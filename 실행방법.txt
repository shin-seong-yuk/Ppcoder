신성욱 게임 개발 포트폴리오 / 학번 202355547

온라인 주소: https://shinswportfolio.vercel.app/

압축을 푼 폴더에서 터미널을 열고 다음 명령어를 입력합니다.

  node server.cjs

그다음 브라우저에서 http://localhost:8000/ 을 엽니다.
Node.js가 설치되어 있어야 합니다. 별도의 npm 설치나 빌드는 필요하지 않습니다.

첫 화면의 프로젝트 이름을 누르면 상세 팝업이 열립니다. 3D 연습장 표적을
맞추면 해당 프로젝트의 본문으로 스크롤합니다. 연습장은 건너뛰어도 됩니다.
모바일에서는 프로젝트 바로가기 버튼으로 동일한 내용을 볼 수 있습니다.
소개 영상은 assets/video 폴더의 로컬 파일이므로 인터넷 없이 재생됩니다.
게임 배포 페이지 및 GitHub 링크를 열 때는 인터넷 연결이 필요합니다.

주의: 온라인 주소는 제출 당시의 Vercel 배포본입니다. 이 압축파일에 추가한
EXIT_FROM·Elevator 실제 게임 이미지가 온라인에도 보이려면 Vercel에 최신
파일을 다시 배포해야 합니다.
